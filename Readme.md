# ThumbPay - Pay with a Touch

ThumbPay is a simple front-end web project that demonstrates a fingerprint-based payment concept. Users can register their thumbprint, link a payment method, and make payments with a touch.

This project was created to practice HTML and CSS, including webpage structure, navigation, sections, buttons, and responsive layout basics.

## Features

- Modern landing page for the ThumbPay payment concept
- Navigation menu with links to different sections
- “How It Works” section explaining the payment process
- Benefits section highlighting the main advantages
- Security section explaining fingerprint verification and data protection
- Get Started section with a registration call-to-action
- Clean and simple responsive design using HTML and CSS

## Technologies Used

- HTML5
- CSS3

## How It Works

1. Register your thumbprint.
2. Link your preferred payment method.
3. Touch to pay at a supported shop.
4. Receive an instant payment confirmation.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.

You can also open the project using VS Code Live Server:

1. Install the **Live Server** extension in VS Code.
2. Right-click `index.html`.
3. Select **Open with Live Server**.
